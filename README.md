# Control Arcade Personalizado - Proyecto Semana TP

## Descripcion del Proyecto
Controlador arcade zero-latency con Arduino Pro Micro, joystick analogico y sensor de golpe.

## Esquema de Conexiones
- Joystick Eje X: Pin A0 (A / D)
- Joystick Eje Y: Pin A1 (W / S)
- Boton Joystick: Pin 3 (X)
- Sensor Golpe: Pin 9 (Z)
